
Display face for MiBand 10 for my own use.

Compiled with MiCreate (on Windows).

Started using Digital Minimalist face by krishnamafia (https://amazfitwatchfaces.com/mi-band/view/517),
but heavily modified.

Weather icons are powered from Tomorrow.io (from https://github.com/Tomorrow-IO-API/tomorrow-weather-codes)
